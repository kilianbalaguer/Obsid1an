About

ShardFetch is a system information tool for jailbroken iOS devices, inspired by neofetch and fastfetch. Run shardfetch in your terminal to see your device info alongside a rainbow Apple logo.

Features
  • Rainbow Apple ASCII art with ANSI colors
  • Device model, iOS version, jailbreak detection
  • CPU chip name and core count
  • Memory and storage usage
  • Battery level and charging status
  • Shell and terminal detection
  • Auto-detects rootful, rootless, and roothide
